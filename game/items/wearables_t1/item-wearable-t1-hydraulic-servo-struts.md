# Hydraulic Servo-Struts

> *"When the operation goes south, you don't have to outrun the security drones—just the rest of the squad."*

## Overview

The **Hydraulic Servo-Struts** guarantee safe extraction when an encounter collapses, completely negating stage failure HP penalties and Tactical Retreat injuries for the wearer.

## Equipment Profile

* **Slot Requirement:** `[Legs]`
* **Quartermaster Cost:** `3 [CR]` *(1.5 ES Value)*
* **Deck Quantity:** 1 Copy
* **Equipment Type:** Failure & Retreat Safety

## Core Mechanics

* **Emergency Disengagement:** If a stage fails or the squad declares a **Tactical Retreat**, this character takes **0 HP damage** from stage failure penalties and suffers no retreat injuries.
